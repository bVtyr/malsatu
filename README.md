# MalSatu — маркетплейс живого скота, мяса и услуг (Казахстан)

**MalSatu** («мал сату» — продажа скота) — mobile-first веб-платформа (PWA, устанавливается на главный экран) для купли-продажи живого скота, мяса и сопутствующих услуг во всех регионах Казахстана. Два равноправных языка — казахский и русский.

> Статус: реализован **MVP** (этап 1 по ТЗ) + доменная логика и схема БД для этапов 2–3 (безопасная сделка, споры, биржа перевозок, карантинные зоны, индекс цен, складчина/согым, аукционы, ветосмотр). Подробная матрица — в [docs/ROADMAP.md](docs/ROADMAP.md).

## Стек (кратко)

| Слой | Выбор | Почему |
|---|---|---|
| Язык | TypeScript везде | один язык, общая доменная логика и валидация (zod) между API и web в пакете `@malsatu/shared` |
| API | Fastify 5 | быстрый, schema-first, лёгкий; WebSocket и rate-limit из коробки |
| БД | PostgreSQL 16 + PostGIS + pg_trgm + unaccent | геопоиск по радиусу и кластеры на карте, полнотекст kk/ru с опечатками, JSONB для конструктора атрибутов |
| Доступ к БД | Kysely + SQL-миграции | типобезопасный SQL без «магии» ORM; PostGIS и tsvector пишутся напрямую |
| Очереди/кэш | Redis (BullMQ-ready) | в MVP фоновые задачи — setInterval; интерфейс задач уже чистый, переезд на BullMQ — замена runner'а |
| Медиа | S3-совместимое (MinIO локально) + sharp | сжатие под слабый интернет, водяной знак, pHash для дублей; в проде — объектное хранилище в РК |
| Web | Next.js 15 (App Router) + собственная CSS-система (`public/malsatu.css`) | SSR для SEO-лендингов «регион/категория», PWA (manifest + service worker + Background Sync), лёгкие страницы |
| Карты | Leaflet + OSM-тайлы | бесплатно, офлайн-кэш тайлов через SW; серверная кластеризация |
| Тесты | Vitest | быстрые юнит-тесты доменной логики (сделки, комиссии, складчина, карантин, индекс цен, OTP, поиск) |

## Быстрый старт

Требования: Node.js ≥ 20, pnpm 9 (`corepack enable`), Docker (для PostGIS/Redis/MinIO).

```bash
cp .env.example .env                 # при необходимости поправить DATABASE_URL и т.п.
pnpm install
pnpm db:up                           # PostGIS + Redis + MinIO в Docker
pnpm db:migrate                      # применить SQL-миграции (apps/api/migrations)
pnpm db:seed                         # справочники + тестовые пользователи + ~40 объявлений (kk/ru, все регионы)
pnpm dev                             # API: http://localhost:4000 (Swagger: /docs), Web: http://localhost:3000
```

Отдельно: `pnpm --filter @malsatu/api dev`, `pnpm --filter @malsatu/web dev`, фоновые задачи вручную — `pnpm --filter @malsatu/api jobs [имя]`.

Бакет MinIO `malsatu-media` создайте в консоли http://localhost:9001 (malsatu / malsatu123) и сделайте его публичным на чтение — либо укажите другое S3-хранилище в `.env`.

### Тесты

```bash
pnpm test                                   # все пакеты
pnpm --filter @malsatu/shared test          # доменная логика: сделки, комиссии, складчина, карантин, индекс цен, аукцион, антифрод, поиск…
pnpm --filter @malsatu/api test             # сервис сделок (in-memory repo), OTP, компиляция поискового SQL, тихие часы
```

### Полезные команды

| Команда | Что делает |
|---|---|
| `pnpm db:reset` | дроп схемы → миграции → сиды (только не в production) |
| `pnpm --filter @malsatu/api jobs price-index` | пересчитать индекс цен |
| `pnpm --filter @malsatu/api jobs quarantine-apply` | применить карантинные зоны к объявлениям |
| `pnpm --filter @malsatu/api jobs --loop` | запустить планировщик задач отдельным процессом (`JOBS_INLINE=false` у API) |
| `docker compose -f infra/docker-compose.yml --profile full up --build` | полный стек в Docker |

## Что подключить извне

SMS-шлюз, подменные номера (телефония), платёжный партнёр (v2), S3-хранилище в РК, тайлы карт/геокодер, госсервисы (ИИН/БИН через ЭЦП/eGov, база идентификации животных ИСЖ), автоперевод, Web Push (VAPID), мониторинг. Интерфейсы адаптеров и переменные окружения — в [docs/INTEGRATIONS.md](docs/INTEGRATIONS.md).
